# 確認したいこと

1. **巡航速度35-36km/hの情報をどう評価するか**: これはロードマップの最終目標(v_max=35km/h)と直接一致する。Phase2(v_max段階引き上げ)の目標設定が妥当だったことの裏付けと考えてよいか
2. **steer rate limit変更(0.8→0.6)の影響評価**: 単位・対応するconfig.yamlパラメータ(`steer_rate_max`かどうか)はアップデート取得後の実測が必要だが、もしAWSIM側のアクチュエータ制約が厳しくなるなら、**現在のMPC内部モデル(QP制約`max_steering_rate`、2026-07-03実測基準で確定した`steer_rate_max=1.1`)がシミュレータの新しい実際の制約と乖離**し、蛇行(飽和・遅延)の一因になりうると考えている。この理解は妥当か。もし妥当なら、Part C実験にsteer_rate_maxの再較正も含めるべきか
3. **Part C実験の実施タイミング**: (a)今週中に現行環境でPart Cを予定通り進め、アップデート後に必要に応じて再検証する、(b)アップデート取得(金曜日)を待ってから、特にsteer rate limitの変更を実測確認した上でPart Cを進める、のどちらが良いか。Phase1の出口ゲート期限(08/06)との兼ね合いも考慮してほしい
4. **1位handicap強化の戦略的な意味合い**: 終端速度25km/h付近というのは、独走時の速度制限を指すと考えているが、これは今回のPhase1(蛇行対策)やPhase2(v_max引き上げ)の設計判断にどう影響するか。単独走行時の想定最高速度が25km/h程度に抑えられるなら、35km/hを目指す設計変更の優先順位が変わる可能性もあるか
5. **総合判断**: 上記を踏まえ、Part C実験計画(実験マトリクス・実施順序)に変更が必要か、それとも計画通り進めてよいか
