# 前提(再検討不要、確定済みの事実)

## これまでの調査チェーン(6段階)
1. レート飽和検査: 成分B(κ非依存)が支配的
2. (A)排除検査: 蛇行は物理現象(EKFアーティファクトではない)
3. Q[e_y]対数スイープ(n=1): 直線層std・コーナー振幅が単調増加、200k-2.8Mで蛇行が約2倍
4. 絞り込みラウンド(200k/400k/700k×n=2): 直線層stdの単調性がn=2で再現、Q200000が勝者。副産物としてwp280-281(既知ホットスポット)で2/6run衝突(Q依存性不明、別課題として保留)
5. **Q[e_psi]発見**: config.yamlのQ=[e_y, e_psi, t, delta_actual]=[200000(勝者), 100000000, 200000, 0]——**Q[e_psi]がQ[e_y]の500倍**という極端な値と判明
6. **Q[e_psi]スイープ(本日実施、結果は下記)**: 直線は改善するがコーナーに代償

**ユーザーの目視観察**: Q[e_psi]=1000000の走行で「コーナーで結構後ろに入っている(向きの追従が遅れている)」「コーナーでハンドルを切りすぎている場面がある」ことを確認。Q[e_psi]=200000ではさらに「蛇行はないがコーナーで不安定」と報告。

## 観察された複雑なパターン

- **直線層std**: Q[e_psi]を下げるほど単調に改善(5.6-6.1°→3.22°→2.42-2.48°→2.33°)。Q[e_y]スイープ単独の改善(床5.82°)を大きく上回る
- **振幅検出不能数**: Q[e_psi]を下げるほど増加(0→3→6→4→7)。これが「きれいに収束している証拠」なのか「振動ではなく別種の不安定さ(向き遅れ型のドリフト)でピーク検出の枠組みに乗らないだけ」なのか、この分析だけでは判別できない
- **ホットスポットp50(中央値)**: 基準(0.75m)に対し、2e7で最も悪化(1.58m)、5e6/1e6/2e5でも0.89-1.21mと軒並み上昇。ただしp95/maxは1e6が全条件中最良(1.09m/1.11m)という非直線的な結果も混在
- 振動周波数(freq_hz)自体もQ[e_psi]低下に伴い緩やかに低下する傾向(ループの実効的な「硬さ」が下がっている物理的な兆候)

# 確認したいこと

1. この複雑なパターン(直線改善・コーナー代償・非単調な部分あり)をどう解釈すべきか。ユーザーの目視観察(向き遅れ・過剰操舵)は「振幅検出不能」の増加と同じ現象を指している可能性が高いと考えているが、この解釈は妥当か。
2. 現時点で最もバランスが取れている候補はどれか。私の初見ではQ[e_psi]=1000000(直線std=2.48°と十分改善、ホットスポットp95/maxが全条件中最良)が有力に見えるが、ユーザーの目視観察(向き遅れ)と矛盾するため確信が持てない。n=1データのノイズをどう評価すべきか。
3. **次に調整すべき第3のパラメータは何か**。「Q[e_psi]を下げるとコーナー進入の向き遅れが生じる」という具体的な失敗モードに対し、以下のような候補を検討している。それぞれの妥当性・優先順位についてアドバイスがほしい:
   - Q[t](現行200000、状態ベクトル3番目、進行方向/時間関連の状態と推測)を調整する
   - wp_id_offset(先読み点数)を増やし、コーナーをより早く先読みして向きのずれを事前に補正する
   - R[delta]を下げる方向(現行500、過去に上げる方向[500→1000]は失敗済み)——向き追従が緩んだ分、操舵の応答性を上げて代償する
   - QN(終端コスト)側のe_psi重みだけを個別調整する
   - 他に検討すべき候補があるか
4. 有力なQ[e_psi]候補が複数残る場合、それぞれについて第3パラメータを個別に振って最も安定する組み合わせを探す、というユーザー提案の進め方(逐次的な多段階探索)は妥当か。それとも他の進め方を推奨するか。
5. 08/25の内部締切を踏まえ、この多段階探索にどれだけ時間を割くべきか。
