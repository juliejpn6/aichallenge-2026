# 前提(再検討不要、確定済みの事実)

wp269-282のホットスポットは、Q値に関わらず間欠的にstall/衝突が発生する既知の別課題(絞り込みラウンドで確認済み)であり、今回のQ選定とは切り離して扱う方針。

## 新たに判明した課題: 追い越し中/ピット中の一時強化Q[e_y]の再検討要否

config.yamlには、通常走行中の`Q[e_y]`とは別に、特定状況で一時的に強化される値が2つ存在する:
- `q_ey_overtake: 5000000.0`(追い越し中、`mpc_controller.py`で`_ot_state=="OVERTAKING"`の間だけQ[0]をこの値に差し替え)
- `q_ey_pit: 50000000.0`(ピット走行中、同様にQ[0]を差し替え、追い越し用と排他)

**経緯調査の結果**:
- `q_ey_overtake=5000000`は、設計当時の基準Q[e_y]=**600000**(現行700000でも200000でもない、gate2開発当時の値)を前提に、`block_half`(相手半径0.5→0.8)・`safety_margin`(1.63→0.8)と**3点セット**で決定された絶対値。個別のスイープ実験や「基準の何倍にするか」という比率設計の記録は見つからなかった
- `q_ey_pit=50000000`は、`q_ey_overtake`の5000000を初期値として流用し、「**Q[e_psi]=1e8に対抗して**狭いピットレーンでレーン中央へ確実に寄せるため」5e7へ引き上げたと明記されている
- 基準Q[e_y]は600000→700000(2026-07-30)→200000(本日)と変遷したが、`q_ey_overtake`/`q_ey_pit`はどちらも一度も追従して見直されていない
- 両者とも**絶対値として実測・調整**されたものであり、基準Q[e_y]からの比率として設計されたものではない

**懸念**: 基準Q[e_y]を700000→200000(3.5分の1)へ下げたことで、`q_ey_overtake`との比率は7.14倍→25倍へ拡大した。さらに`q_ey_pit`の5e7という値は「Q[e_psi]=1e8に対抗するため」という理由だったが、今回Q[e_psi]も1e8→5000000(1/20)へ下げる方向で検討しているため、`q_ey_pit`の存在理由自体が変化している可能性がある。

# 確認したいこと

1. Q[e_y]=200000・Q[e_psi]=5000000という最終候補の確定について、このデータで十分か、追加の確認(n=2化等)が必要か。
2. `q_ey_overtake`(追い越し中)・`q_ey_pit`(ピット中)は、基準Q[e_y]/Q[e_psi]の変更に伴い再チューニングが必要と判断してよいか。それとも「一時的な強化値」である以上、基準値の変動とは独立に(絶対値のまま)据え置いてよい設計思想と考えるべきか。
3. 再チューニングが必要な場合、どちらを優先すべきか(追い越し・ピットどちらの影響が大きいか)。また、新しい基準値(Q[e_y]=200000、Q[e_psi]=5000000)を踏まえた妥当な新しい値の見積もり方(単純な比率スケーリングか、それとも当時と同じ実測・実験による再決定が必要か)についてアドバイスがほしい。
4. `q_ey_pit`の「Q[e_psi]=1e8に対抗する」という設計理由が、Q[e_psi]を下げる今回の変更でどう変わるか(そもそも対抗する必要が減る可能性)。
5. 08/25の内部締切を踏まえ、この追い越し/ピットQ値の再検討にどれだけ時間を割くべきか(通常走行のQ確定を優先し、追い越し/ピット側は後回しでよいか)。
