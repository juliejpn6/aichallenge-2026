# 前提(再検討不要、確定済みの事実)

## Phase 1(レート飽和検査)の実測結果(2026-08-04)
`scripts/analyze_steer_rate_saturation.py`を実装し、実予選ログ7本(2026-08-01〜08-04、tau=190ms基準6本+tau=160ms失敗版1本)全てに適用した。トラック全域をwaypoint窓(≈5m)単位で区切り、各窓の局所蛇行指標(操舵角std、180節と同一定義)を理論必要レート|κ'|·v·L_wb(κ'=dκ/ds、真の空間微分、窓内max-minではない)へ原点通過回帰し、説明できる分(成分A、κ'駆動)と残差(成分B、κ'非依存)に分解した。

**結果、7本全てで成分Bが圧倒的に支配的だった**:
- 回帰R²(wobble ~ |κ'|·v)は全ログで大きく負(-128%〜-2048%)——原点通過回帰が定数に近いターゲットに対して系統的に不良フィットになる、成分Aがほぼ寄与していないことを示すパターン
- トラック全域を|κ'|の四分位で4層(直線/低/中/高swing)に分けたところ、局所蛇行指標(操舵角std)は層間でほぼフラットだった(例: 0801-01ログで直線層10.48° vs 高swing層10.48°、完全に同水準)
- 操舵レート飽和率(実測|dδ/dt|が経験的較正した上限の95%を超えた割合)は全層で0.4-1.2%と低く、高swing層への集中も見られなかった
- 直線区間のwaypoint CSV量子化ノイズ検査(κ'のRMS・点間隔の変動係数)では、直線幾何は綺麗でアーティファクトではないと確認——パスキンク補正(Phase 3)は直線側の蛇行には効かないことを意味する

## 過去2つの独立した実測との収束
この結果は、design_docs/stage15_perf_20260707.htmlの2つの既存の発見と完全に整合する:
- **180節(2026-07-25、実予選ログ)**: 蛇行はトラック全体で一様に悪化しており、シケイン(高swing区間)に限局していなかった(直線でも同水準に悪化)。当時はCPU負荷(否定済み)と対戦車インタラクション(未検証)が疑われていた。
- **263節(2026-08-02、PSD周波数分析)**: OT状態(対戦車対応中)の限界サイクル帯(0.5-0.9Hz)パワーはNORMAL状態より低い(0.10-0.78倍)と判明し、「対戦車インタラクションが主因」という仮説は退けられ、焦点が「AXIS06本体(NORMAL時の限界サイクルそのもの)」へ戻された。

**3つの独立した実測(180節・263節・今回のPhase 1)が同じ結論に収束している**: 蛇行はコーナー形状(曲率SWING)に起因する過渡応答ではなく、AXIS06本体(delta_actualモデル、Q[e_y]、tau=190msの相互作用)に起因する、曲率に依存しない機構(自己励起的な限界サイクル、または恒常的な不安定性)である可能性が高い。

# 私(Claude)の見解(検証していない推測を含む、以下すべて明示的に推測扱い)

3つの独立した実測が「AXIS06本体、κ非依存」という同じ方向を指している以上、次はこの機構自体を直接検証すべきだと考えている。具体的な仮説として、「Q[e_y](横偏差追従ゲイン)とtau=190ms(アクチュエータむだ時間+一次遅れ)の相互作用が、閉ループ全体を0.6-0.7Hz付近でわずかに減衰不足(またはマージナルに不安定)な状態にしており、GNSS/EKFノイズや微小な外乱が常時この帯域を励起し続けている」という可能性を考えている。もしこれが正しければ、蛇行は「入力(曲率変化)への応答」ではなく「常時存在する自己励起的な限界サイクル」であり、曲率がゼロの直線でも、EKFノイズ等のわずかな励起源さえあれば同じ振幅で観測されることと整合する。

ただしこれは検証していない仮説であり、他の説明(例: 何らかの周期的な外乱源、GNSS更新周期との相互作用、EKF自体の推定ダイナミクス、Q[e_psi]側の寄与等)も排除できていない。

# 確認したいこと

1. 「Q[e_y]×tauの相互作用による自己励起的限界サイクル」という私の仮説は、制御理論的に妥当か。他に見落としている可能性のある説明(GNSS/EKF起因、Q[e_psi]起因、離散化誤差起因等)はあるか。
2. この仮説を検証するための、次の**具体的で実行可能な実験・分析**は何か。候補として以下を検討しているが、優先順位・実現可能性へのアドバイスがほしい:
   - (a) 閉ループの線形化モデル(MPC+delta_actual状態+Q[e_y]/tau)の固有値解析——0.6-0.7Hz付近に減衰の小さい極があるかを解析的に確認する
   - (b) 実車で直線区間を走行させ、e_yへの人工的な微小外乱(例: 一時的なQ[e_y]の変更、または初期姿勢のわずかなオフセット)を注入し、その後の収束波形が0.6-0.7Hzでringingするかを実測する(既存の`analyze_corner_ringing.py`のアンサンブル解析手法をコーナー通過ではなく人工外乱注入イベントに転用できないか)
   - (c) Q[e_y]の値を系統的に振ったローカルA/B(v_max=20、対戦車なし、直線区間中心のコース、または直線が多い簡易コース)で、蛇行振幅がQ[e_y]にどう依存するかを実測する
3. もし(a)の固有値解析が現実的なら、必要なモデル化の粒度(車両モデル・アクチュエータモデル・EKF込みか制御則のみか)についてアドバイスがほしい。
4. 過去に「Q[e_y]曲率スケジュール(v1-v5)は全て失敗した」という記録([[q-ey-tuning-jitter-vs-offset]]、壁ペナルティ・チャタリング等)があるが、これは「曲率に応じてQ[e_y]を動かす」アプローチの失敗であり、今回検討したいのは「Q[e_y]の基準値自体(曲率非依存)がtauとの相互作用で不適切な可能性」である。この違いを踏まえても、過去の失敗パターンから学ぶべき教訓はあるか。
