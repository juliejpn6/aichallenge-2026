あなたは自動運転レーシングカート(ROS2 Humble / Autoware、spatial MPCで制御)のソフトウェアアーキテクトです。Q[e_y]対数スイープ・絞り込みラウンドに続く次の一手として、Q[e_psi](姿勢追従ゲイン)のスイープを計画しています。実験を始める前に、この計画自体が妥当かレビューしてほしいです。

# 前提(再検討不要、確定済みの事実)

## これまでの調査チェーン(5段階)
1. レート飽和検査(Phase 1): 成分B(κ非依存)が支配的と判明、rate-saturation仮説は主因ではない
2. (A)排除検査: 蛇行はEKFアーティファクトでなく物理現象と確定(gnss/ekf比1.06-1.09)
3. Q[e_y]対数スイープ(n=1、200k-2.8M): 直線層std・コーナー出口振幅が明確な単調増加
4. 絞り込みラウンド(200k/400k/700k×n=2): 直線層stdの単調傾向がn=2でも統計的に頑健に再現(条件間差0.19-1.10°のばらつきに対し条件間差1.5-2.2°)。ラップタイムも同順で改善(トレードオフなし)
5. **副産物**: 6run中2run(400k・700k各1)でwp280-281(既知ホットスポットwp269-282内)の同一地点で壁衝突。直前の単発スイープでは同じQ700000で衝突していないため、Q依存性は不明・地点固有の間欠的脆弱性の可能性が高いと判断し、Qチューニングとは別課題として保留

## Q[e_psi]発見の経緯
config.yamlのQベクトルは`[e_y, e_psi, t, delta_actual]`の4要素形式(delta_actual状態拡張込み)。現行値は`Q: [700000.0, 100000000.0, 200000.0, 0.0]`——**Q[e_psi]=100,000,000は、絞り込みラウンドの勝者であるQ[e_y]=200,000の実に500倍(基準700,000との比較でも143倍)**という極端な大きさであることが判明した。

Q[e_y]を200,000まで下げても直線層stdは5.82°と残存しており(ゼロには程遠い)、この残存分にQ[e_psi]の過大なゲインが関与している可能性がある。この仮説は、あなたが以前の相談(Q[e_y]×tau自己励起仮説の初回検証時)で代替仮説として挙げていた「Q[e_psi](ヨー角偏差ゲイン)の高すぎ: 横偏差だけでなく姿勢を無理に合わせようとするあまり、ステアリングを過剰に切り返し、結果的に横偏差のオーバーシュートを招いている可能性」と一致する。

なお、R[delta](操舵レートコスト、現行500)の静的引き上げ(500→1000)は2026-07-23節で既に試され、直線・シケインいずれも悪化して撤回済みという記録があるため、この筋は除外している。

# 私(Claude Code)の計画案(実行前、レビュー対象)

Q[e_y]スイープと同じ手法(既存ログの`analyze_steer_rate_saturation.py`による直線層std 4層分析+`analyze_corner_ringing.py`によるコーナー出口振幅・ホットスポットp95|ekf_ey|)を、Q[e_psi]の対数スイープに適用する。

- **固定値**: Q[e_y]=200000(絞り込みラウンドの勝者)、他の条件(v_max=20・solo・delay=0.055較正値)は不変
- **スイープ候補**: Q[e_psi] = 100000000(現行基準)/ 50000000 / 20000000 / 10000000 / 5000000 の5点(対数的に約20倍のレンジ)
- **規模**: まずn=1で5点回して傾向を見る(Q[e_y]スイープの時と同じ進め方)、傾向が明確なら絞り込みラウンド(n=2)へ

# 確認したいこと

1. この計画の妥当性: Q[e_y]を200000に固定した状態でQ[e_psi]を振る、という設計は適切か。それともQ[e_y]は基準値(700000)に戻してQ[e_psi]の純粋な効果を切り分けるべきか。
2. スイープ候補の値(1e8→5e6、5点)は妥当か。Q[e_psi]を下げすぎることによる副作用(姿勢を全く追従しなくなり、コーナーで向きが合わないままオフセットだけで曲がろうとする、等)について、制御理論的に懸念すべき下限はあるか。
3. Q[e_y]とQ[e_psi]は同時に(2次元グリッドで)振るべきか、それとも今回のように「Q[e_y]を固定してQ[e_psi]だけ振る」逐次的なアプローチで十分か。相互作用(交絡)を見逃すリスクをどう評価するか。
4. wp280-281の衝突(副産物として発見、Qとの因果関係未確定)は、今回のQ[e_psi]スイープの実施判断に影響すべきか、それとも完全に独立の課題として今は無視してよいか。
5. 08/25の内部締切を踏まえ、この実験(n=1で1時間弱)に着手する優先度は妥当か。
